## What Adam's reference example means for the site

The forwarded example is an operational model: an applicant names a referee; the system sends a request; the writer uploads a confidential letter; a reusable generic letter can serve multiple authorized applications, while tailored letters are also possible. The example is not a template to publish verbatim and is not an employer account for RESI.

The site should explain only the candidate-facing steps. It should link to an activated institution-specific application destination, where applicable. The applicant should not be asked to upload their own confidential recommendations, and writer links must never be placed in public source or website content.
